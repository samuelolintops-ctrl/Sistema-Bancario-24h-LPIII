# Sistema Bancário 24 Horas

Projeto prático desenvolvido para a disciplina de **Linguagem de Programação III (LP III)**
---

## Sobre o Projeto

O **Sistema Bancário 24 Horas** simula operações de um autoatendimento bancário.

### Principais Funcionalidades
- **Gestão de Clientes:** Cadastro e vínculo de clientes.
- **Operações Bancárias:**
  - Depósitos e saques.
  - Consulta de saldo e extrato.
  - Transferências entre contas.
- **Persistência de Dados:** Salvamento e recuperação do estado dos dados das contas/sessões com o pickle.
